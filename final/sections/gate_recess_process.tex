\chapter{Gate Recess Process Engineering}
\label{ch:gate-recess-process}

This chapter will describe the Semester 2 process innovations that enabled
precise gate recessing, including calibration structures, etch timing models,
and oxide management.

\section{Process Objectives}
Define the targeted recess depths, allowable tolerances, and link to the
threshold-voltage goals set in Chapter~\ref{ch:introduction}.

\section{Etch Chemistry Selection and Calibration}
Report measured etch rates, agitation schemes, and profilometry data for the
H$_2$SO$_4$:H$_2$O$_2$:H$_2$O solution. Include lessons from calibration chips.

\section{Native Oxide Mitigation}
Detail the HCl dip procedure, timing constraints, and any surface-analysis
results.

\section{Mask and Layout Strategy}
Explain the quadrant-based recess matrix, sample labelling convention, and any
cleanroom logistics considerations.
